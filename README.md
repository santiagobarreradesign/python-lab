# Python Lab

A second course, beside the design-engineer lab.
Same rules. Different language.

Source: [Asabeneh / 30 Days of Python](https://github.com/Asabeneh/30-Days-Of-Python).
We did not paste the lessons. We kept the order and cut each day down to one idea.

## How we work

- One concept per evening. About two hours.
- You type every line. I do not write your code.
- If you get stuck: hint, then a bigger hint, then a nudge. Full answer only if you ask after trying.
- You explain the idea back in your own words before we move on.
- You commit to Git at the end of each session.

## Folders

- `roadmap.md` — the 30 days, in order
- `sessions/` — tonight’s notes and exercises
- `practice/` — your code lives here. You create the files.
