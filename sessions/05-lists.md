## What this session is for

A **list** is a row of values in square brackets:

```py
fruits = ["apple", "banana", "mango"]
```

Like a string, positions start at **0**.

You can:

- read one item: `fruits[0]`
- count items: `len(fruits)`
- add an item: `fruits.append("orange")`
- remove an item: `fruits.remove("banana")`
