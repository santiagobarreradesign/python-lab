## What this session is for

An **operator** is a symbol that tells Python to do something with values.

Math ones:

| Symbol | Meaning | Example | Result |
|--------|---------|---------|--------|
| `+` | add | `3 + 2` | `5` |
| `-` | subtract | `3 - 2` | `1` |
| `*` | multiply | `3 * 2` | `6` |
| `/` | divide | `7 / 2` | `3.5` |
| `//` | divide, drop the leftover | `7 // 2` | `3` |
| `%` | leftover after divide | `7 % 2` | `1` |
| `**` | power | `2 ** 3` | `8` |

Compare ones (answer is always `True` or `False`):

| Symbol | Meaning |
|--------|---------|
| `==` | are these the same? |
| `!=` | are these different? |
| `>` `<` `>=` `<=` | bigger / smaller |

Remember: `=` puts a value in a name. `==` asks if two things are equal.
