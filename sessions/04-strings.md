## What this session is for

A **string** is text. You wrap it in quotes:

```py
name = "Santiago"
```

You can:

- glue text with `+`
- count letters with `len`
- grab one letter with `[0]` (counting starts at **0**, not 1)
- grab a piece with `[0:3]` (from index 0 up to, but not including, 3)
